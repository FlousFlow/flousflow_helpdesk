Helpdesk (Flous Flow)

Support tickets linked to repair orders

Manage customer support tickets with teams, stages and tags, and link each ticket to a physical repair order. Installing this module automatically installs the standard repair module.

Key Features

  • Tickets with teams, stages, tags and priorities
  • Kanban view grouped by stage
  • Full lifecycle: New -> In Progress -> Done / Cancelled
  • Create a repair order directly from a ticket
  • Bidirectional link: ticket ↔ repair order
  • Printable ticket (PDF report)
